# Optical-Waveguiding-in-Lyotropic-Liquid-Crystals-
Estimate light attenuation and propagation length in dye-doped liquid crystal tubes/fibres from waveguiding videos. ImageJ macros and Python average frames, extract the axial intensity profile, fit exponential decay and report 1/e length, dB/µm and loss per tube diameter. Supports scale-bar calibration and per-frame batch analysis.
